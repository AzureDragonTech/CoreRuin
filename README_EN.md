# CoreRuin: Boot From Safe Mode

## 🎮 About

A narrative puzzle game set inside an old computer system.
Explore the device, decode messages and make choices leading to different branches.

## ✨ Features
- Terminal-style boot screen at start, GUI system for the main content
- Cipher decryption puzzles
- Built-in chat program for interaction
- Choice-driven branching paths

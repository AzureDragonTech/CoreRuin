# 残核：自安全模式启程
> CoreRuin: Boot From Safe Mode

## 🎮 简介
一款以老旧电脑系统为舞台的解密叙事游戏。
在设备之中探索、破译信息、做出抉择，体验多条不同分支路线。

## ✨ 特性
- 开场带有终端风格启动画面，主体为图形界面系统
- 密码破译类解谜
- 内置聊天交互程序
- 选择驱动多分支剧情
